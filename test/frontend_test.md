# 述格 (ScriptGrid) 前端测试文档

## 1. 文档概述

### 1.1 测试目的

本文档为述格 (ScriptGrid) 前端页面的手工测试文档，旨在确保前端各功能模块的交互行为、视觉展示、国际化支持和无障碍访问符合预期。

### 1.2 测试范围

| 模块 | 涉及文件 |
|------|---------|
| 页面加载与布局 | `index.html`, `style.css` |
| 文件选择与类型识别 | `app.js` |
| 转换类型动态选项 | `app.js` |
| 语言选择（SUP） | `app.js`, `i18n.js` |
| 表单提交与转换流程 | `app.js`, `progress.js` |
| SUP 转换进度显示 | `progress.js`, `app.js` |
| 国际化（中英文切换） | `i18n.js` |
| 页面关闭确认 | `page-close.js`, `task-manager.js` |
| 消息提示 | `app.js` |
| 无障碍访问 | `index.html`, `style.css`, `i18n.js` |
| 响应式设计 | `style.css`, `index.html` |

### 1.3 测试环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Microsoft Edge（最新版） |
| 设备 | 桌面端（1920×1080）、平板端（768×1024）、手机端（375×667） |
| 后端服务 | 本地运行 `uvicorn app:app --host 0.0.0.0 --port 8000` |
| 网络 | 正常网络 |

### 1.4 测试数据准备

| 数据类型 | 说明 |
|---------|------|
| 有效 .ass 文件 | 包含多条字幕的标准 ASS 字幕文件 |
| 有效 .srt 文件 | 包含多条字幕的标准 SRT 字幕文件 |
| 有效 .xlsx 文件 | 表头为"序号/开始时间/结束时间/字幕内容"的 Excel 文件 |
| 有效 .sup 文件 | PGS 图像字幕文件（用于 OCR 识别测试） |
| 空字幕文件 | 0 条字幕的 .srt 文件 |
| 非法格式文件 | .txt, .pdf, .docx 等不支持的格式 |
| 大体积文件 | 超过 10MB 的字幕文件（边界测试） |
| 文件名含特殊字符 | 文件名包含中文、空格、括号等字符 |
